--------------------------------------------------------------------------------
WHY THIS ONE
--------------------------------------------------------------------------------

Same device and same architecture as ours:

  - E-mode GaN HEMTs, not SiC
  - a SEGMENTED output stage - the driver is split into slices
  - drive strength selected by a PATTERN, not set by a resistor

That is the structure this project starts from.

--------------------------------------------------------------------------------
HOW WE EXTEND IT
--------------------------------------------------------------------------------

  Theirs                                  Ours
  ------------------------------------    ------------------------------------
  ASIC, fixed pattern set                 every field programmable from an
                                          FPGA: slices, dead time, clamp,
                                          off-bias rail
  strength set by one bias resistor       720-point control word
  pattern chosen at design time           we measure what choosing it per
                                          operating point is worth
  no Miller clamp                         separately-timed active clamp
  no negative off-bias rail               selectable 0 V / -2 V

The result: choosing the pattern well is worth 25.1 %; changing it per
operating point adds 3.9 %, and one comparator captures 72 % of that.

--------------------------------------------------------------------------------
NOTE ON THE EARLIER BASE PAPER
--------------------------------------------------------------------------------

Takayama, Okuda & Hikihara (Int. J. Circuit Theory Appl., 2022,
doi 10.1002/cta.3136) was previously listed as the base paper. It is not, and
the deck no longer says it is: that paper is on SiC MOSFETs, not GaN.

It stays in the reference list at [9] as prior art for the mechanism - the
idea that switching behaviour can be chosen by a digital code rather than by
a resistor. The PDF is in 5-BASE-PAPER/ for reference. The numerical
comparison against it has been removed from the deck.
